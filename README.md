# BrandForge AI

مولّد هويات بصرية ومطبوعات ذكية بدعم كامل للعربية (RTL)، مبني وفق وثيقة المواصفات.

## التشغيل

```bash
npm install
cp .env.example .env.local   # اختياري: أضف GEMINI_API_KEY
npm run dev
```

ثم افتح http://localhost:3000

بدون مفتاح Gemini يعمل التطبيق كاملاً بالمحرك المحلي (ألوان، قصة، شعارات، مطبوعات، تصدير). عند إضافة المفتاح تُصاغ القصة والألوان والخطوط والإرشادات عبر Gemini بإخراج JSON منظم، ثم تمر على طبقة التحقق.

## منع التكرار

- بذرة ديناميكية لكل طلب (`crypto.getRandomValues` + بصمة المدخلات) تُمرَّر إلى Gemini (`seed`) وإلى محرك الشعارات.
- 7 عائلات رموز (شبكة، نجمة إسلامية، مدارات، كتل منظورية، بتلات، أعمدة/أقواس، كوفي مربع) يُختار منها 3 مختلفة بأوزان حسب النمط والقطاع.
- القائمة السلبية مطبقة في نص الطلب وفي البناء نفسه (لا منازل، لا عربات تسوق، لا دوائر مزدوجة متطابقة، لا شارات).
- زر «مفاهيم جديدة» يقلل وزن العائلات المعروضة سابقاً.

## ملاحظات الطباعة

- ملفات PDF بدقة 300 DPI، مع هامش قص 3 مم وعلامات قص وصناديق TrimBox/BleedBox.
- الملفات بنظام RGB؛ قيم CMYK في الدليل تحويل مرجعي، والتحويل النهائي لدى المطبعة بملف تعريفها اللوني.
- النصوص في ملفات SVG تعتمد على الخطوط المذكورة (مجانية من Google Fonts).

## محرك الشعارات v2
- يقرأ الاسم (يتجاوز «ال» والكلمات العامة مثل شركة/مطعم/مقهى) ونوع النشاط، ويختار رموزاً خاصة بالقطاع (`lib/logo/motifs.ts`).
- **المُركِّب** (`lib/logo/composer.ts`): يبني كل شعار لحظة الطلب من محاور مستقلة: النواة (حرف، حرفان، رمز نشاط) × 18 إطاراً × 5 معالجات × 4 حلي × 8 لمسات × 3 أنظمة ألوان × مقياسان. هذا يعطي أكثر من 120 ألف تركيبة لكل علامة، و1.5 مليون تقريباً إجمالاً. `compositionSpace()` تحسب العدد الفعلي لكل علامة.
- منع التكرار: كل تصميم له مفتاح تركيبي (`signature`)، وما عُرض سابقاً لا يُعاد.
- السرعة: دفعة من 6 مفاهيم في أقل من 1 مللي ثانية تقريباً، داخل المتصفح بلا خادم.

## تجربة الذكاء الاصطناعي (تجريبي)
`lib/ai-trial.ts` يولّد أفكار شعارات كصور عبر Pollinations.ai، وهي خدمة مجانية بلا مفتاح، للاستلهام فقط. الصور نقطية وقد تحتوي أخطاء في الحروف. للإنتاج استبدلها بـ Recraft (SVG متجهي) عبر مسار خادم.

## الحسابات: إدارة + ديمو
| الحساب | الدخول الافتراضي (تطوير) | الصلاحيات |
|---|---|---|
| إدارة | `admin` / `admin123` | كل شيء + لوحة `/admin` (الحسابات وحالة الإعدادات) |
| ديمو | `demo` / `demo1234` | الاستوديو والتصدير كاملاً بالمحرك المحلي، **بدون** استهلاك Gemini |

- **الوضع الافتراضي عام:** أي زائر يفتح التطبيق مباشرة كحساب ديمو بدون تسجيل دخول، ولوحة الإدارة على `/login`. لجعل التطبيق يتطلب الدخول: `PUBLIC_DEMO=false`.
- الحماية في `proxy.ts` (Next.js 16).
- الجلسة كعكة HttpOnly موقّعة HMAC-SHA256 لمدة أسبوع، وفيه حد لمحاولات الدخول (10 كل 10 دقائق لكل IP).
- **في الإنتاج:** اضبط `AUTH_SECRET` و `ADMIN_PASSWORD` إجبارياً. بدونهما يتعطل حساب الإدارة وكلمة المرور الافتراضية `admin123` ما تشتغل. بيانات الديمو تُغيَّر أو يُعطَّل الحساب عبر `DEMO_ENABLED=false`.

## الرسم المباشر بالذكاء الاصطناعي
- `lib/ai-logo.ts`: يبني وصفاً دقيقاً من الاسم ومعناه والنشاط والقيم والنمط والألوان ونوع الشعار والعناصر المفضلة والممنوعة.
- **Recraft** (`RECRAFT_API_KEY`): شعارات SVG متجهية حقيقية بألوان الهوية، حوالي 0.08 دولار للشعار.
- **Gemini** (`GEMINI_API_KEY`) بديل أرخص يرسم SVG مباشرة. يُستخدم تلقائياً لو ما فيه مفتاح Recraft، أو لو فشل Recraft.
- كل SVG ينظَّف: يُحذف السكربت والروابط والصور الخارجية والخلفية البيضاء. يشتغل في الشعار الكامل والأحادي والمطبوعات والنمط والتصدير.
- الديمو العام: 3 دفعات شعارات و5 هويات بالساعة لكل زائر (`DEMO_AI_*`).

## حسابات العملاء ولوحة التحكم
- **التسجيل قبل الدفع:** العميل يسجّل ببريده أو جواله برمز تحقق من 6 أرقام. صلاحية الرمز 10 دقائق، و5 محاولات كحد أقصى، ودقيقة بين كل إرسال والثاني.
- **الباقات:** خياران لكل منتج — مرة واحدة أو اشتراك شهري (الأسعار من `NEXT_PUBLIC_PRICE_ONCE` و`NEXT_PUBLIC_PRICE_MONTHLY`). لا توجد تجربة مجانية بمدة.
- **المعاينة مجانية بعلامة مائية:** العميل يصمم ويعدّل ويشوف كل شيء، والتحميل بعد الدفع فقط. الملفات المصدّرة بعد الدفع بدون علامة مائية.
- **المسودة غير المدفوعة:** تبقى `DRAFT_DAYS` أيام (الافتراضي 7) ليكمل الشراء، وطلب التفعيل يمددها. بعد الدفع تصبح دائمة.
- **التفعيل حتى ربط بوابة الدفع:** العميل يضغط «اختر هذه الباقة» فيصلك الطلب في تبويب «الطلبات والمدفوعات»، وبعد استلام المبلغ تضغط «تفعيل». الشهري يمتد شهراً ويُجدَّد بزر «تجديد شهر».
- **متى يُطلب التسجيل:** عند «احفظ تصميمي»، وقبل التحميل. ويوجد حفظ تلقائي بعد كل تعديل.
- **«تصاميمي»:** تفتح التصميم من أي جهاز، وتشوف الأيام المتبقية، وتقدر تحذفه.
- **لوحة التحكم `/admin`:**
  - نظرة عامة: الإيراد، والاشتراكات الشهرية، وطلبات التفعيل، ورسوم يومية.
  - زر «إضافة بيانات تجريبية» يضيف 100 عميل: 58 مرة واحدة، و34 مشترك شهري، و4 ألغوا، و4 طلبات تفعيل، مع زيارات 900 زائر جربوا ولم يدفعوا. وزر «حذف البيانات التجريبية» يزيلهم ويرجّع الأرقام بالضبط.
  - المالية (للمالك فقط): الإيراد الفعلي حسب الباقة، والتكاليف من عدد العمليات × سعر الوحدة، والمصاريف الثابتة لهذا التطبيق، والزكاة التقديرية، وصافي الربح لـ 30 أو 90 يوماً أو سنة. كل سعر قابل للتعديل من البيئة: `COST_AI_LOGO_SAR`، `COST_DISH_PHOTO_SAR`، `COST_AI_IDENTITY_SAR`، `COST_MENU_AI_SAR`، `COST_NAME_CHECK_SAR`، `COST_SMS_SAR`، `GATEWAY_PCT`، `GATEWAY_FIXED_SAR`، `FIXED_VERCEL_SAR`، `FIXED_EMAIL_SAR`، `FIXED_REDIS_SAR`، `FIXED_LEGAL_SAR`، `ZAKAT_RATE`.
  - الطلبات والمدفوعات: طلبات التفعيل، وتفعيل مرة واحدة أو شهري، وتجديد، وإلغاء.
  - العملاء: بحث، وتفعيل كل تصاميم العميل، وملاحظة، وحذف، وتصدير CSV.
  - التصاميم: كلها أو المدفوعة أو المسودات القريبة من الحذف، مع تفعيل لكل تصميم.
  - الاستخدام والتكاليف: عمليات الذكاء الاصطناعي وتكلفتها التقديرية.
  - الفريق (للمالك فقط): إضافة أعضاء بصلاحية «مشرف» (يفعّل الطلبات ويدير العملاء والتصاميم) أو «مشاهد» (قراءة فقط)، مع تغيير الصلاحية وكلمة مرور جديدة وإيقاف وحذف.
    - المالك هو حساب `ADMIN_USERNAME`/`ADMIN_PASSWORD` من متغيرات البيئة، ولا يمكن تعديله أو حذفه من اللوحة.
    - إدارة الفريق وحذف العملاء والإعدادات للمالك فقط.
    - كلمات مرور الأعضاء مخزنة كبصمة PBKDF2، وأي تغيير في الصلاحية أو كلمة المرور أو الإيقاف يُخرج العضو فوراً.
  - الإعدادات (للمالك فقط): قائمة جاهزية الخادم.
- **وضع العرض:** في الإنتاج بدون Upstash Redis، لوحة الإدارة تعرض 100 عميل تجريبي في ذاكرة الخادم تلقائياً، مع شريط تنبيه. تسجيل العملاء الحقيقيين يبقى متوقفاً حتى تربط القاعدة.
- **حدود الذكاء حسب المستخدم:** الزائر يحصل على شعارين تجريبيين بـ Gemini فقط، والمسجّل اللي ما دفع شعارين بالدفعة وحد يومي صغير، والدافع التوليد الكامل (`lib/ai-tier.ts`).
- **رمز الدخول بالجوال:** على واتساب (WhatsApp Cloud API)، وSMS احتياطي اختياري. البريد عبر Resend.
- **الأسعار والخصومات (لوحة التحكم):** تعديل أسعار الباقات بدون إعادة نشر، وأكواد خصم بنسبة أو مبلغ، لباقة أو الاثنين، مع حد استخدام وتاريخ انتهاء. العميل يطبّق الكود في نافذة الدفع، والتفعيل يحسب السعر المخفّض ويزيد عدد الاستخدام.
- **صلاحيات الفريق:** مشرف أو مشاهد أو صلاحيات مخصصة (تفعيل المدفوعات، إدارة العملاء، حذف التصاميم، المالية، الأسعار والخصومات، البيانات التجريبية، وحذف المنيوهات في سُفرة). التطبيق فوري.
- **المتطلبات:** Upstash Redis، ومزود بريد (Resend) أو جوال (Twilio أو Unifonic). للتجربة فقط: `OTP_DEV_ECHO=true` يعرض الرمز على الشاشة.
